# Provider marks

The chat provider SVGs are the brand marks used by the
[reference documentation](https://convrt-five.vercel.app/docs/api/), retrieved
from its `/brands/chat/` assets. They identify links to ChatGPT, Claude, v0,
t3.chat, Scira, and Cursor. These marks belong to their respective owners and
do not imply endorsement of Cloud Tools.

## Technology marks

The website and social preview use Next.js, TypeScript, Bun, and Terraform marks from
[Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons).
The SVGs are stored locally so `bun run brand:build` needs no network access.
These marks identify technologies used by Cloud Tools and belong to their
respective owners; they do not imply endorsement.
